# Sadhu ❤️ — Birthday Surprise

Standalone HTML/CSS/JavaScript birthday experience for Sadhu, from Baal.

## Files
- `index.html`
- `images/01_mystery.png` ... `images/12_devices.png`

The images are cropped directly from the generated cinematic artwork so the website uses the same visual artwork.

## Run
Open `index.html` in a browser, or deploy the folder to GitHub Pages.

## Interaction
The highlighted button is the only way to advance between scenes. There is no automatic scene timer.

## Sound
The melody is original and generated with Web Audio API; no copyrighted music file is included.
